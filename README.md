# Morocco Shop

A Laravel and Inertia e-commerce platform for Morocco.

## Main rules

- Cash on Delivery only
- No Stripe and no online card payment
- Guest checkout is the default
- Customers order on the website first
- Laravel saves the order before WhatsApp opens
- WhatsApp is used for confirmation
- Customers pay when the delivery arrives
- Accounts are optional for order history and saved addresses
- Admin manages products, stock, delivery fees, orders, customers, and analytics
